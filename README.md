# Abandoned Office Escape Room
Click the buttons and read the prompts to try to escape from an abandoned office. Can you do it?

I want to make more of these, so if you have any ideas, let me know! I will credit you if I choose your idea!

This is a game I made in PowerPoint in March 2026, so I decided to remake it in Scratch since I never shared the PowerPoint version, and it took me F O R E V E R to do. 

140 blocks and a lot of broadcast messages later, I did it!
